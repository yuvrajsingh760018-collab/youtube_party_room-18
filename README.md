# 🎬 YouTube Watch Party

A real-time YouTube Watch Party application where multiple users can join the same room and watch YouTube videos together with synchronized playback.

## 🚀 Features

- Create a watch party room
- Join a room using a unique room code
- Real-time video synchronization
- Play/Pause synchronization
- Seek synchronization
- Late-joiner synchronization
- Change YouTube video
- Host and Participant roles
- Promote Participant to Moderator
- Remove participants
- Leave room
- Handle user disconnection
- Backend permission validation
- Responsive UI

## 🛠️ Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Socket.IO Client
- React YouTube

### Backend
- Node.js
- Express.js
- Socket.IO
- CORS
